# 01: 统一依赖与测试入口

**What to build:** 任何人在新机器或干净虚拟环境中,按文档一条命令安装全部依赖并运行完整测试套件,不依赖开发者本机的游戏路径或手工预装。包含:声明并锁定运行与测试依赖;建立统一测试命令;现有全部测试纳入该入口;初始化 Git 仓库并提交当前状态,为后续持续集成与公开发布打底。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 干净环境中按文档一条命令完成安装
- [ ] 同一(或第二条)命令运行全部现有测试并给出统一退出码
- [ ] 测试不引用任何本机绝对路径或真实游戏目录
- [ ] 依赖有锁定策略,重复安装得到相同版本
- [ ] 目录成为 Git 仓库并有初始提交,忽略规则覆盖生成物与本机数据(work/、config.json 中的密钥等)
