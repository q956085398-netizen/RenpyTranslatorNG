# 07: 事务式应用与恢复

**What to build:** "应用到游戏"改为事务式:在暂存区生成全部 tl 文件、人名与关系词显示层脚本、字体和语言入口,执行快速结构检查,通过后统一替换进游戏安装,写入应用清单并创建恢复点;任何阶段失败时游戏目录保持应用前状态。统一应用覆盖全部项目资产——包括此前不会刷新的人名与关系词显示层,不存在隐藏例外。支持依据应用清单一键停用汉化。

**Blocked by:** 05(项目数据库:出现位置与译文记录)、06(单项目单写入任务协调器)

**Status:** ready-for-agent

- [ ] 在暂存、检查、替换各阶段注入失败,游戏目录均保持应用前状态(无半应用)
- [ ] 每次应用生成应用清单与恢复点,恢复点可查看差异并还原
- [ ] 应用后人名与关系词显示层、字体、语言入口随译文一并生效
- [ ] 停用汉化只撤销工具管理的文件,保留汉化项目及其资产
- [ ] 应用返回可验证的任务摘要(成功、跳过、待检查数量)
