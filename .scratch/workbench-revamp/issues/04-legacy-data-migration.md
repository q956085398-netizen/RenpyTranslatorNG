# 04: 旧数据自动迁移

**What to build:** 升级首次启动时扫描现有 work/ 目录下的各项目 JSON 数据、游戏库记录文件与应用配置,生成迁移预览和备份,确认后导入注册库与项目存储。迁移幂等,可重复执行而不产生重复数据;无法可靠匹配的内容进入待检查项而非静默丢弃。用户近百条游戏库记录与已付费译文一条不丢。

**Blocked by:** 03(项目注册库与稳定项目身份)

**Status:** ready-for-agent

- [ ] 迁移前展示预览,自动创建备份,失败可从备份恢复
- [ ] 迁移前后项目数量、译文数量、人工修改内容可对账(对账率 100%)
- [ ] 重复执行迁移不创建重复项目或重复译文记录(幂等测试)
- [ ] 无法可靠匹配的内容成为待检查项,带有来源说明
- [ ] 游戏库记录与应用配置保留并可在新结构中正常使用
